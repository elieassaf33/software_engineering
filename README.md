# Developer Task Manager

A lightweight personal task management tool for software developers.  
Built with Python and Tkinter as part of the IU Software Engineering project.

## Features
- Create tasks quickly
- Add tool used, context notes, and tags
- View all tasks in a simple list
- View full task details
- Mark tasks as completed
- Delete tasks
- Automatic save/load using JSON

## Requirements
- Python 3
- Tkinter (included with most Python installations)

## How to Run
```bash
python main.py
```
