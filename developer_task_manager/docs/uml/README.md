# UML sources

The 14 `.mmd` files are editable Mermaid sources and reflect the implementation.
Verified SVG renders are included in `rendered/`. Regenerate with a
Mermaid-enabled Markdown editor or Mermaid CLI:

```powershell
npx -y @mermaid-js/mermaid-cli -i use-case.mmd -o use-case.svg
```

Rendering was verified on 2026-08-04 with Mermaid CLI invoked through `npx`.
Node.js and Mermaid CLI are documentation tools, not application runtime
dependencies.
